# Portfolio image staging

This directory is reserved for optimized artwork, process, portrait, and project images used by the public portfolio.

## Naming

Use lowercase, descriptive, hyphenated filenames. Prefer stable names based on the work rather than upload order.

Examples:

- `threshold-study-01.jpg`
- `ceramic-figure-rust-glaze.jpg`
- `stagecraft-fabrication-process-01.jpg`
- `spencer-brown-studio-portrait.jpg`

## Recommended preparation

- Export photographic images as high-quality JPG or WebP.
- Keep the longest edge around 2000–2400 px for primary portfolio images unless a larger source is specifically needed.
- Avoid embedding private location, device, or identifying metadata when exporting.
- Preserve an archival master outside this repository; repository images should be web-ready derivatives.

## Metadata to collect with each selected work

- title
- year
- medium/materials
- dimensions where applicable
- photographer credit if not Spencer Tracy Brown
- short context or project note when useful

Do not publish student-identifying images or third-party copyrighted material without appropriate permission.
