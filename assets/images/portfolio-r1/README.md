Deployment rules:

- Preserve archival originals outside this repository.
- Publish only web derivatives with embedded metadata removed.
- Do not alter the artwork itself; documentary corrections may include crop, perspective correction, exposure/color refinement, and resizing.
- Confirm title, year, medium, dimensions, and photographer credit before adding final captions.
- Do not publish identifiable student or third-party images without appropriate permission.
- Scenic/fabrication and public/educational slots should remain unfilled until stronger permission-safe documentation is available rather than forcing unrelated work into those categories.
