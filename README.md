# Spencer Tracy Brown — Portfolio

Standalone portfolio and professional website for Arizona artist, sculptor, creative fabricator, and educator Spencer Tracy Brown.

## Current state

The site is intentionally in staging while artwork, metadata, portrait photography, CV materials, and final domain configuration are added.

## Structure

- `index.html` — portfolio homepage
- `assets/css/styles.css` — standalone visual system
- `assets/images/` — artwork and process images to be added

## Publishing

The intended production path is GitHub Pages with a dedicated custom domain. Search indexing remains disabled in the HTML until the portfolio is ready for public discovery.
